## 1. 創作方向

- **一句話**：金鐘罩震碎箭雨後，劍客轉身躍上屋頂逃走，武僧緊追；兩人在古代城市的屋脊、茶樓、石橋、鐘樓之間追逐交手，最後在鐘樓頂以「雙鐘共鳴」收尾。
- **風格**：2D 日式動畫、賽璐璐上色、粗描邊（同 v1）。武俠電影的運鏡語言：慢快交替、子彈時間、停格打擊。
- **展示重點**（這支片是展示 Claude 動畫能力的作品，以下每一項都要做到位）：
  1. 骨架人偶的流暢動作（跑、跳、翻、空中轉身、出拳、揮劍、受擊、落地緩衝）
  2. 程式產生的古代建築群（每棟不同但風格統一）
  3. 多層視差景深＋動態運鏡（追焦、環繞、螺旋上升、急推急拉）
  4. 粒子物理：碎瓦、木屑、瓷片、水花、燈籠火星、塵煙
  5. 打擊回饋四件套：停格 2–3 格、鏡頭震動、閃白、衝擊漣漪
  6. 冷暖對比：劍客＝冷藍白劍氣，武僧＝暖金罡氣（沿用 v1）

## 3. 角色規格（取自 v1，必須一致）

v1 原始碼：repo 根目錄 `index.html` 的 `drawSwordsman()`、`drawMonk()`。v2 把它們改寫成**骨架人偶**，但外型與配色不變。

### 劍客（A）
- 年輕男性，白色漢服長袍、藍色腰帶與兩條長飄帶、黑色高馬尾、銀色直劍。
- 色票：描邊 `#141726`、袍 `#eef1f8`、袍陰影 `rgba(120,140,190,.3)`、腰帶 `#3d7bff`、飄帶 `#5b93ff`、膚 `#f6dcc7`、髮 `#1d2133`、劍身 `#e9f3ff`、護手 `#c9a24a`、劍柄 `#3a2a1e`。
- 動作性格：輕盈、多空翻與迴旋，落地輕。劍氣冷藍白 `#6ab8ff` / `#d2f0ff`。
- v2 新增：S8 時右袖斷裂（延續 v1 結尾袖子被吹裂）。

### 武僧（B）
- 光頭壯碩，橘紅袈裟斜披一肩、木念珠、金色腰帶，表情沉穩嚴肅。
- 色票：描邊 `#1a1220`、袈裟 `#d8542c`、內側暗面 `#c9472a`、膚 `#e8b38a` / `#e3a47a`、腰帶 `#f2b53a`、念珠 `#5a3420`、褲 `#3a2a3a`。
- 動作性格：沉重、直線、步步踏實，落地有塵爆。罡氣暖金 `#ffcc44` / `#ffe08a`。金鐘罩外形沿用 v1 的 `hw(h)` 鐘形函式。

### 骨架人偶要求
- 骨骼：骨盆、脊椎、頸、頭、左右上臂／前臂／手、左右大腿／小腿／腳，外加附屬物（劍、飄帶、馬尾、袈裟下擺）。
- 兩層動畫：**關鍵姿勢**（手動定義的 pose library）＋**次級運動**（飄帶、馬尾、衣擺用 Verlet 繩索或彈簧模擬，跟著角色速度擺動）。
- Pose library 至少包含：idle、run（循環）、jump-start、air-tuck、flip、land、slash（3 種）、thrust、block、punch、palm-strike、horse-stance、hit-react、wall-climb、stand-off。
- 先做一個 `v2/rig-test.html`：兩個角色並排循環播放所有 pose，並可以切換慢動作，**給使用者確認造型和動作質感後**才進入場景製作。

## 4. 場景與建築產生器

- 寫一個 `ArchitectureKit`：用參數產生古代建築元件，共用同一套描邊與上色規則。
  - 屋頂：歇山頂、硬山頂、捲棚；飛簷起翹曲線、瓦壟線條、屋脊獸
  - 牆身：木構柱樑、斗拱、格窗、白牆灰瓦
  - 特殊建物：牌樓、城門、茶樓（兩層，可破窗、可進入）、石拱橋、多層鐘樓（可繞行）
  - 街景物件：燈籠串、招牌旗幡、攤販棚、水缸、樹
- 每個場景用 3–5 層視差（遠山／遠景剪影／中景建築／角色層／前景遮擋物），每層有自己的霧氣與色調。
- 光線預設：S1 黃昏、S2 冷月光、S3 燈籠暖光（燈籠要是光源，照亮附近屋瓦）、S4 室內燭光、S5 河面月光倒影、S6–S8 高空夜景＋巨大滿月。
- 可破壞物件要能產生碎片粒子：瓦片、門板、燈籠、茶壺、樑柱、水牆。

## 5. 技術架構

```
v2/
├── index.html          ← 播放器＋時間軸＋分鏡跳轉（同 v1 介面風格）
├── rig-test.html       ← 骨架人偶確認頁（M1）
├── js/                 ← 若單檔超過約 300KB 再拆檔；否則全部 inline 在 index.html
├── render/
│   ├── render.mjs      ← Playwright 逐格輸出
│   └── README.md
├── audio/
│   ├── cues.json       ← 由動畫時間軸自動匯出的音效／台詞時間表
│   ├── scripts/        ← 在使用者電腦上跑的語音與音效生成腳本
│   ├── stems/          ← 生成的 wav（不 commit 大檔，見 .gitignore）
│   └── mix.py          ← 混音
└── out/                ← 成品（不 commit，改用 Release）
```

### 時間軸
- 單一 `TIMELINE`：每個鏡頭定義 `t0, t1, scene, camera keyframes, character tracks, events`。
- `events` 同時驅動畫面特效與聲音提示，匯出成 `audio/cues.json`：`{t, type:"sfx"|"line", id, desc, character?, intensity}`。**聲音與畫面對位的唯一來源就是這個檔案。**
- 時間變速（慢動作、停格）沿用 v1 的 `timeScale(t)` 做法；cues 的時間一律是**輸出影片時間**，不是模擬時間。

### 逐格輸出（雲端或本機都可以跑）
- 網頁提供 `window.__renderFrame(frameIndex)`：seek 到 `frameIndex / 60` 秒並同步畫完一格。
- `render.mjs` 用 Playwright（Chromium）開 `v2/index.html?render=1`，逐格取出 canvas PNG，pipe 給 ffmpeg：
  `ffmpeg -f image2pipe -framerate 60 -i - -c:v libx264 -preset slow -crf 16 -pix_fmt yuv420p out/silent.mp4`
- 這種做法不受電腦效能影響，不會掉格；這是成片品質的關鍵。

## 6. 聲音製作

### 6.1 角色配音（本機 GPU）
| 用途 | 工具 | 授權 |
|---|---|---|
| 主力：雙人對白、用文字描述設計聲線 | OpenMOSS **MOSS-TTSD** ＋ **MOSS-VoiceGenerator**（https://github.com/OpenMOSS/MOSS-TTS） | Apache-2.0 |
| 情緒、喘息、怒吼、冷笑 | **Step Audio EditX** | Apache-2.0 |
| 備案（VRAM 不足） | **VoxCPM2**（可 CPU）、**GLM-TTS**、MOSS-TTS-Nano（CPU） | Apache-2.0 |
| 付費備案（品質最穩） | ElevenLabs MCP（https://github.com/elevenlabs/elevenlabs-mcp），有免費額度 | 商用服務 |

- 聲線設計：
  - 劍客：年輕男中音，清亮、帶傲氣，語尾上揚，語速稍快。
  - 武僧：渾厚男低音，沉穩，語速慢，句尾帶胸腔共鳴（後製加一點短殘響）。
- 除了台詞，也要生成**非語言發聲**：出招吐氣、受擊悶哼、跳躍呼吸、怒喝（每人每種 3–5 個變化版本，避免重複感）。
- 每句台詞生成 4–6 個版本，挑最好的；兩人的音色要跟角色一致，不能前後漂移。

### 6.2 音效
| 層 | 工具 | 用途 | 授權 |
|---|---|---|---|
| 生成 | **MOSS-SoundEffect v2.0**（48kHz、中英文描述、最長 30 秒） | 所有音效素材 | Apache-2.0 |
| 對位補強（選用） | **MMAudio V2**（看影片生音效） | 腳步、碎瓦的時間對位 | 權重非商業，Q3 回覆「不營利」才用 |
| 程式合成 | Python（numpy/scipy）或 Web Audio | 劍氣嗡鳴、鐘聲泛音、超低頻衝擊 | 自寫 |

- 每個重要打擊點做**分層音效**：瞬態（高頻、2–20ms）＋主體（中頻）＋重量（60Hz 以下）＋尾巴（殘響或碎片落地）。
- 腳步：劍客＝輕快踏瓦；武僧＝重踏＋瓦片微碎。依角色速度自動決定步點。
- 環境音床：每個場景一條（風、夜市人聲、室內木頭吱嘎、河水、高空風）。
- 配樂：先不做，或只做 S7 前的低頻鼓點與上升音（Q4 問使用者）。

### 6.3 混音
- `mix.py` 讀 `cues.json`，把 stems 放上時間軸；做淡入淡出、音高與音量的小幅隨機化、ducking（台詞出現時壓低音效）。
- S7 劍觸鐘前 0.5 秒**全靜音**，之後雙鐘齊鳴，這是全片最大聲的一刻。
- 響度：整體 −14 LUFS（YouTube 標準），true peak ≤ −1 dBTP：
  `ffmpeg -i mix.wav -af loudnorm=I=-14:TP=-1:LRA=11 final.wav`
- 合成：`ffmpeg -i out/silent.mp4 -i final.wav -c:v copy -c:a aac -b:a 320k out/wanjian-fx-v2.mp4`

### 6.4 GPU 工作分工
雲端環境沒有 GPU。語音與音效生成腳本放在 `audio/scripts/`，寫成在使用者的 Windows 電腦（PowerShell、NVIDIA GPU）上一鍵執行：建立 venv → 安裝 → 讀 `cues.json` → 輸出 wav 到 `audio/stems/`。附 `audio/scripts/README.md` 用繁體中文寫清楚步驟與常見錯誤。

## 8. 品質檢查清單（交付前逐項確認）

- [ ] 兩個角色在每個鏡頭的造型、配色和 v1 一致
- [ ] `seek(t)` 兩次輸出同一格，畫面逐像素相同（確定性）
- [ ] 60fps 輸出無掉格；動態模糊與速度線不閃爍
- [ ] 每一次打擊都有停格、震動、閃白、聲音四件事同時發生
- [ ] 台詞與嘴型、出招吐氣與動作同步，誤差 ≤ 2 格
- [ ] S7 的 0.5 秒靜音確實是靜音
- [ ] 響度 −14 LUFS ± 1，無破音
- [ ] 手機寬度（400px）下網頁版可操作、不溢出
- [ ] 所有使用的模型與素材授權列在 `v2/CREDITS.md`
