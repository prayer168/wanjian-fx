# 開工指令（複製下面整段貼給 Claude Code）

在 `wanjian-fx` 資料夾開啟 Claude Code（建議選 Opus 5.5 模型），貼上：

```
你要製作《萬箭金鐘罩 II：瓦上追風》。

1. 先讀 CLAUDE.md 和 docs/v2/PRODUCTION_PLAN.md，完整讀完再動手。
2. 從里程碑 M0 開始：把規格書第 0 節的四個問題問我（顯示卡、2D 或 3D、是否營利、腳本是否調整）。
3. 拿到答案後做 M1：v2/rig-test.html，兩個角色的骨架人偶和全部 pose。做完先給我看，我確認後才做下一步。
4. 每完成一個里程碑就 commit 並推送，然後停下來等我確認。
5. 不要改動根目錄的 index.html（v1 已上線）。
```

## 之後每個階段可以這樣說

- 「M1 可以，繼續 M2。」
- 「劍客跑步太僵硬，膝蓋彎曲再大一點，飄帶延遲再長一點。」
- 「S3 樣片可以，做完整 8 個鏡頭。」
- 「語音檔跑好了，放在 audio/stems/，開始混音。」
