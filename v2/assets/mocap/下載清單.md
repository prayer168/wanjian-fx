# Mixamo 動作下載清單

網址：https://www.mixamo.com （用 Adobe 帳號登入，免費）

## 每個動作的下載設定（都一樣）

1. 左邊搜尋框輸入下面的關鍵字，點一個動作預覽
2. 右邊若有「In Place」勾選框：**不要勾**（要保留真實位移）
3. 按右上角 **Download**，設定：
   - Format：**FBX Binary (.fbx)**
   - Skin：**Without Skin**
   - Frames per Second：**60**
   - Keyframe Reduction：**none**
4. 下載的檔案**不用改名**，全部放進這個資料夾：
   `C:\Users\user\Documents\wanjian-fx\v2\assets\mocap\`

第一個檔請另外用 **Skin: With Skin** 下載任意一個動作（例如 Idle），並改名成 `_skeleton.fbx`，我用它對齊骨架。

每個關鍵字挑 **1～3 個**看起來最帥、最乾淨的就好。搜尋結果名字可能略有不同，挑最接近的。
