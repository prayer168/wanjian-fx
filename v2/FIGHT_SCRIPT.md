# 萬箭金鐘罩 II：瓦上追風 — 打鬥劇本 v2

> 2026-11-12。依使用者回饋重寫：兩人幾乎每個鏡頭都在、從頭打到尾；劍客招式華麗多變，和尚使出少林各種絕學；有輸有贏；運鏡多樣。

## 一、原則

1. **一直在打**：每一幕的場景鏡頭不再空拍，背景就是戰場，人物永遠在畫面裡。
2. **停—爆—停**（香港動作片的節奏）：短暫對峙 → 一連串快攻 → 一個定格或慢動作收尾，再進下一輪。
3. **每一招只為一個鏡頭設計**（香港動作片的「分鏡頭拍攝」）：先決定鏡位，再讓招式朝那個方向亮相。
4. **讓觀眾「感覺到那一下」**：命中瞬間要有衝擊格、震動、碎片和音效。
5. **有輸有贏**：每一幕結尾都交代誰佔上風，最後一招兩敗俱傷，彼此敬重。

## 二、招式表

### 劍客（全部為本片原創命名，靈感來自武俠劍法的類型）

| 招式 | 特效 |
|---|---|
| 驚鴻一閃 | 拔劍快到看不見：先閃白，下一格劍已收回，對手身後的東西才裂開 |
| 迴風三疊 | 三連斬，每一斬留下一道藍白色新月劍氣 |
| 劍雨 | 揮劍上天，數百把光劍從天而降插滿地面 |
| 御劍 | 劍離手，在空中自己飛行繞敵三圈再回到手上 |
| 萬葉化刃 | 劍氣捲起竹葉，每片葉子變成發光的小刃射向對手 |
| 斷水 | 劍掃過水面，掀起三公尺水牆再一劍劈開 |
| 九霄劍陣 | 數十把光劍在身後排成圓陣，像孔雀開屏，依序射出 |
| **萬劍歸宗**（終極） | 上萬把光劍從城市上空升起，盤旋成龍捲，再聚合成一把百公尺巨劍，刺向金鐘罩 |

### 和尚（少林寺流傳的傳統武功名稱）

| 招式 | 特效 |
|---|---|
| 金鐘罩 | 金色鐘形護體，只在最危急時才用 |
| 鐵布衫 | 皮膚泛起青銅色光澤，硬吃一劍，劍身彈開冒火花 |
| 羅漢拳 | 快速連打，身後浮現金色羅漢虛影跟著出拳 |
| 大力金剛掌 | 單掌推出一個巨大的金色掌印，地面龜裂 |
| 般若掌 | 雙掌合十再推出，一圈圈經文般的光環向前擴散 |
| 龍爪手 | 五指成爪，空中出現金色龍爪虛影，抓住飛來的劍 |
| 一指禪 | 一根手指點出一道細金光，把飛來的光劍一一點碎 |
| 旋風腿 | 騰空旋踢，捲起塵土與落葉的龍捲 |
| 獅子吼 | 聲波成環，震碎周圍一切，竹林倒伏 |
| **千手如來掌**（終極） | 身後浮現千手金身虛影，上千個掌印同時迎向萬劍 |

## 三、各幕勝負與節奏

| 幕 | 場景 | 主要交手 | 結果 |
|---|---|---|---|
| 序幕 | 月下城外山脊 | 兩道身影在山脊上飛掠交錯，一劍一掌碰出火花 | 開場 |
| 一 | 荒原 | 劍客「劍雨」→ 和尚金鐘罩擋下 → 和尚「大力金剛掌」把劍客震飛 | **和尚佔上風** |
| 二 | 城門、屋脊 | 「御劍」追擊 → 「龍爪手」抓住飛劍 → 「羅漢拳」連打 → 劍客「驚鴻一閃」脫身，斬落整串燈籠成火雨 | **劍客扳回** |
| 三 | 竹海 | 竹梢上「迴風三疊」對「旋風腿」→「萬葉化刃」→「一指禪」點碎 →「獅子吼」 | **和尚勝**，劍客被震落 |
| 四 | 雨夜石橋 | 「斷水」水牆 →「般若掌」劈開 → 近身十二連擊 → 劍客劍尖劃斷念珠 | **劍客勝**，念珠散落水中 |
| 五 | 鐘樓 | 邊打邊上塔：「九霄劍陣」對「鐵布衫」，一層層打碎飛簷 | 平手，塔頂對峙 |
| 六 | 塔頂 | 「萬劍歸宗」對「千手如來掌」＋金鐘罩，雙鐘共鳴 | **兩敗俱傷**：巨劍碎成星光，金鐘裂而不破 |
| 尾聲 | 塔頂 | 兩人互相抱拳，背對滿月 | 惺惺相惜 |

## 四、鏡頭語言（每一幕都要混用）

| 鏡頭 | 用法 |
|---|---|
| 大遠景／空拍 | 每幕開場交代地形，人物是畫面中的小點 |
| 俯視（鳥瞰） | 劍陣、劍雨、金鐘罩的圓形構圖從正上方看最好看 |
| 低角度仰拍 | 和尚出大招、劍客躍起時，讓人物有份量 |
| 中景、近景 | 交手主體，看清楚招式 |
| 特寫、大特寫 | 眼神、握劍的手、劍尖、腳踩水窪 |
| 搖臂升降（crane） | 從人物拉起到城市全景，或從天降到劍尖 |
| 跟拍（tracking） | 屋脊追逐、繞塔上升 |
| 甩鏡（whip pan） | 兩人互換攻勢時快速甩到另一人，也當轉場 |
| 急推（crash zoom） | 大招命中前一瞬猛推到眼睛或劍尖 |
| 推軌變焦（dolly zoom） | 和尚發「獅子吼」、劍客看見萬劍升空時的震撼 |
| 子彈時間環繞 | 動作慢下來，鏡頭繞人物半圈 |
| 變速（speed ramp） | 快 → 慢動作看清楚命中 → 再加速 |
| 手持晃動 | 近身快攻 |
| 主觀鏡頭（POV） | 從劍尖看向金鐘罩 |
| 淺景深 | 特寫時背景虛化，焦點從一人轉到另一人 |

## 五、轉場

不再淡出到黑畫面。改用：

- 甩鏡轉場
- 動作接動作（match cut）：前一幕最後的動作，接下一幕同方向的動作
- 物件轉場：竹葉、雨滴、火星飛過鏡頭後換場
- 必要時用溶接

## 六、聲音

- **配樂**：一首從頭到尾連貫的曲子，同一個主題、同一個速度網格，跟著打鬥起伏，不在每幕重新開始。
- **音效**：比 v1 降低約 3 dB。
- **靜音**：第六幕衝擊前保留全靜音。
