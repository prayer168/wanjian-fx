# VRoid Studio 捏人設定表（劍客＋武僧）

> 用途：做出《萬箭金鐘罩 II》兩位主角的高細緻模型，匯出成 VRM 交給 Claude 接上動作與特效。
> 預估時間：每位角色 40–60 分鐘。
> 注意：VRoid Studio 版本不同，選單名稱可能略有差異；數值都是「大約」，以看起來像為準。

---

## 0. 開始之前

1. 到 VRoid 官網下載安裝 **VRoid Studio**（免費，Windows 版）。
2. 開新模型時選 **男性（Masculine）** 範本，兩位角色各開一個檔案。
3. 下面寫「上色」的地方，都直接把色碼貼進顏色欄位（例如 `#eef1f8`）。

### VRoid 做不到也沒關係的東西
這些我會在程式裡另外做好，接在角色的骨架上，**您不用做**：
- 劍客：**長劍、劍鞘、兩條藍色長飄帶**
- 武僧：**斜披的袈裟布、念珠、金色腰帶、綁腿**、頭頂戒疤
- 兩人的武功特效、金鐘罩、劍氣

您只要專心把 **臉、頭髮、身材、基本衣服、鞋子** 做好。

## 1. 劍客

**形象**：二十出頭的年輕俠客，清秀帶傲氣，白衣如雪，黑色高馬尾，動作輕盈。

### 臉（Face）
| 項目 | 設定 |
|---|---|
| 臉型 | 偏瘦長的鵝蛋臉，下巴稍尖 |
| 眼睛 | 細長、外眼角微微上揚（劍眉星目）；眼睛不要太大，偏「少年漫畫」而不是「少女漫畫」 |
| 瞳孔顏色 | 深藍黑 `#1d2a4a`，高光保留 |
| 眉毛 | 劍眉：粗細中等、尾端上挑，顏色 `#1d2133` |
| 嘴 | 小、薄，預設表情帶一點自信微笑 |
| 膚色 | `#f6dcc7` |

### 頭髮（Hairstyle）
| 項目 | 設定 |
|---|---|
| 主體 | **高馬尾**：頭頂盤一個小髮髻，馬尾長度到背中間 |
| 瀏海 | 中分或稍微偏分，兩側各留一撮長鬢髮垂到下巴 |
| 顏色 | `#1d2133`（高光可用 `#3a4466`） |
| 髮帶 | 綁髮髻處加一條細髮帶，顏色 `#3d7bff` |

> 馬尾請用「髮束（Hair group）」做成**獨立一束**，我才能讓它跟著動作甩動。

### 身材（Body）
| 項目 | 設定 |
|---|---|
| 身高 | 偏高（約 175–178 公分的比例） |
| 頭身比 | 約 7.5 頭身，不要 Q 版 |
| 體型 | 修長、肩膀中等、腰細，不要肌肉男 |

### 衣服（Outfit）
| 部位 | 設定 |
|---|---|
| 上衣 | 選最接近**長袍／和服類**的範本，改成**交領（左襟壓右襟）**；顏色 `#eef1f8`，陰影色 `#c4cde6` |
| 袖子 | **寬大的廣袖**，袖口到手腕下方 |
| 下襬 | 長到小腿中間，下襬寬鬆 |
| 衣領邊、袖口邊 | 細邊條 `#3d7bff` |
| 腰帶 | 藍色寬腰帶 `#3d7bff`（飄帶我另外做） |
| 褲子 | 深藍 `#2c3150` |
| 鞋子 | 黑色布靴 `#1d2133`，靴筒到小腿 |

## 2. 武僧

**形象**：三十多歲的壯碩武僧，光頭，濃眉怒目但沉穩，像一座山。

### 臉（Face）
| 項目 | 設定 |
|---|---|
| 臉型 | 方臉、下顎寬、顴骨明顯 |
| 眼睛 | 偏小、眼神銳利，上眼瞼稍壓低（嚴肅、怒目的感覺） |
| 瞳孔顏色 | 深褐 `#3a2418` |
| 眉毛 | **濃粗**，眉頭低、眉尾上揚，顏色 `#2a1a18` |
| 鼻子 | 鼻樑寬一點 |
| 嘴 | 嘴角平或微微下垂，閉嘴 |
| 膚色 | `#e8b38a`（比劍客深、偏日曬） |

### 頭髮（Hairstyle）
| 項目 | 設定 |
|---|---|
| 頭髮 | **全部刪除，做成光頭** |
| 頭皮 | 底色設成跟膚色一樣 `#e8b38a`（不要留黑色髮際線） |

> 頭頂六個戒疤我會在程式裡加，您不用畫。

### 身材（Body）
| 項目 | 設定 |
|---|---|
| 身高 | 比劍客高半個頭（約 185 公分的比例） |
| 頭身比 | 約 7 頭身 |
| 體型 | **壯碩**：肩膀寬、胸厚、手臂粗、腰也粗，但不是胖 |

### 衣服（Outfit）
| 部位 | 設定 |
|---|---|
| 上衣 | 選**無袖或短袖的長袍**範本；顏色 `#d8542c`，陰影色 `#c9472a` |
| 右肩 | 盡量**露出右肩與右臂**（如果範本做不到，整件無袖也可以，斜披的袈裟布我另外做） |
| 下襬 | 長到膝蓋下方 |
| 褲子 | 深紫灰 `#3a2a3a`，寬鬆 |
| 鞋子 | 布鞋 `#2a1e28` |

## 3. 兩人共同：必須保留的東西

1. **表情（Expressions）全部保留不要刪**：喜、怒、哀、驚、眨眼，以及口型 あ・い・う・え・お。我要用它們做表情和台詞的嘴型。
2. **髮束、裙襬的搖動設定（Spring bone）保留**，我會再調整。

---

## 4. 匯出 VRM

1. 右上角 **匯出（Export）→ VRM**。
2. 版本選 **VRM 1.0**（如果沒有就選 VRM 0.0，也可以）。
3. **減面（Polygon reduction）不要開**，材質貼圖尺寸選 **2048**。
4. 授權資訊（License / Metadata）：
   - 作者：黑熊老師（或您的名字）
   - **商業使用：允許**
   - 其他欄位依您的意願
5. 檔名：
   - 劍客：`swordsman.vrm`
   - 武僧：`monk.vrm`
6. 把兩個檔案放到：`wanjian-fx\v2\assets\characters\`（資料夾我已經建好）

做好一位就可以先給我，我會先接上動作，渲染一段給您看。

## 5. 常見問題

| 問題 | 解法 |
|---|---|
| 找不到交領的衣服範本 | 選一般長外套，衣領之後我在程式裡補交領邊條 |
| 光頭有接縫或黑線 | 把頭皮與髮際線的顏色都改成膚色 |
| 匯出很慢或失敗 | 先關掉其他程式；貼圖尺寸改 1024 再試 |
| 想參考別人的漢服素材 | 網路上（例如 BOOTH）的素材要先看授權是否**允許商用**，不確定就不要用 |
