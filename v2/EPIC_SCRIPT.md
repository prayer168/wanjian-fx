## 一、調研摘要：可以借鏡的手法

### 1. 武俠電影的打鬥拍法
| 手法 | 出處／依據 | 這部片怎麼用 |
|---|---|---|
| **招式為鏡頭而設計**：每個角度單獨編排動作，而不是一套動作用多台攝影機去拍 | Bordwell 談香港動作片 | 每顆鏡頭自己設定攝影機位置與角色走位，招式朝鏡頭「亮相」 |
| **低角度中景**：讓角色更有份量 | Bordwell 談張徹 | 武僧出場、金鐘罩、鐘樓對峙用低角度仰拍 |
| **廣角遠景把人縮小**，在靜止構圖與狂亂運鏡之間切換 | 《英雄》分析 | 每幕開場用大遠景交代場景，打到高潮改手持快切 |
| **鏡頭滑行跟著打鬥，最後停在特寫** | 《臥虎藏龍》分析 | 竹林一幕用長鏡頭滑行，招式收尾停在眼神特寫 |
| **雨夜、接近單色、慢動作特寫手腳、雨滴與碎片** | 《一代宗師》開場雨戰 | 第四幕「雨橋」：慢動作雨滴、水花、腳踩水窪的特寫 |
| **吊鋼絲的輕功身法** | 臥虎藏龍、武俠片傳統 | 劍客踏竹梢、踏水、牆上奔走 |

### 2. 日式動畫作畫手法
| 手法 | 做法 |
|---|---|
| **衝擊格（impact frame）**：命中那一刻插入 1–2 格反差強烈的閃白、黑白反轉或放射線 | 每次重擊插入 2 格（60fps 下約 1/30 秒） |
| **拖影格（smear）**：最快的動作才用，1–2 格 | 揮劍軌跡用拉長的半透明形體＋劍氣弧光 |
| **速度線沿物體真正的軌跡**，越快越密 | 劍氣弧線是沿著劍尖實際路徑生成的 |
| **出招瞬間被閃光、特寫或拖影遮住**（「一閃」演出） | 劍客絕招「一劍流星」：畫面先白，下一格已經收劍，對手身後的物件才裂開 |

### 3. 音效設計
- **不要只用單一音效**：重擊疊 2–4 層（瞬態＋主體＋重量＋尾巴），出拳前一定要有破風聲。
- **衣物摩擦聲**會讓拳腳更真實。
- **聲音比畫面早 1–2 格**，抵消感知延遲。
- 同一把劍從頭到尾用同一個「劍鳴」聲紋，每次音量與音高隨機微調，避免機械重複。
- 武打片的拳腳聲偏短促、高頻明顯，破風聲刻意誇大。

### 4. 素材與授權（可營利）
| 素材 | 來源 | 授權 |
|---|---|---|
| 樹木、岩石、草叢 | Quaternius Stylized Nature MegaKit（含 glTF） | CC0，可商用 |
| 天空 HDRI、PBR 材質（瓦片、木頭、石材） | Poly Haven、ambientCG | CC0 |
| 基礎動作（跑、跳、翻滾） | Adobe Mixamo | 可免版稅用於影片；不可單獨轉售原始檔 |
| 角色（建議方案） | VRoid Studio 自己捏人，匯出 VRM，用 `@pixiv/three-vrm`（MIT）載入 | 自己做的角色版權歸自己 |
| 中式古建築 | 找不到可靠的 CC0 模型，**用程式產生**（ArchitectureKit）＋CC0 材質 | 自寫 |
| 語音／音效／配樂 | 沿用規格書的 Apache-2.0 本機模型；配樂另選授權允許商用的開源音樂模型（使用前逐一確認授權） | Apache-2.0 等 |

## 三、專業建議

### 建議 1：最大的品質關鍵是角色模型。建議改用 VRoid 捏人（需要您花 1–2 小時）
用程式拼出來的角色，細緻度有天花板。M1 樣片已經看得出來：臉、頭髮和衣服都是幾何體拼的。您要的「非常非常細緻」，最可靠的做法是：
1. 您用免費的 **VRoid Studio**（Windows）照兩人的設定捏人：髮絲、五官、眼睛高光、漢服、袈裟、念珠、鞋子都可以細調。我會附一份逐項設定表，照著填就好。
2. 匯出 VRM 檔給我。我用 `three-vrm` 載入，接上我寫的骨架、招式、表情（眨眼、怒目、嘴型對台詞）和布料物理。
3. 角色版權屬於您，可以營利。

**替代方案**：如果不想自己捏，我繼續用程式加強模型：細分曲面、髮片、貼圖畫出的五官。會比現在好很多，但不會達到 VRoid 的水準。

### 建議 2：場景用「寫實環境＋動漫角色」的混合風格
參考現代 3D 國漫與動畫電影：環境用 PBR 寫實材質、HDRI 夜空、體積霧、月光光柱；角色保留賽璐璐上色＋描邊。這樣角色在畫面上會跳出來，場景又有您要的逼真感。
- 樹木、竹子、岩石：Quaternius CC0 模型
- 中式建築：我寫程式產生（歇山頂、斗拱、飛簷、瓦當），貼 CC0 寫實材質
- 夜空：程式產生的星空與銀河＋可調的巨大滿月（有月面紋理、光暈）

### 建議 3：渲染後製全開（離線渲染不怕慢）
因為是逐格輸出，不需要即時跑，可以把特效開到最滿：泛光（bloom）、景深（特寫背景虛化）、動態模糊、每幕不同的調色、底片顆粒、體積光、衝擊格、拖影格。估計每格 1–3 秒，4 分鐘共 14,400 格，**一次完整渲染約 4–12 小時**，可以整晚放著跑。

### 建議 4：聲音分三軌製作
1. **對白與發聲**：本機 GPU（≥8GB）跑 MOSS-TTSD / Step Audio EditX（Apache-2.0），每句生成多個版本挑最好的。
2. **音效**：MOSS-SoundEffect 生成素材，再用程式依時間軸自動分層、對位、隨機化。
3. **配樂**：建議加。史詩感很大一部分來自配樂。方向是太鼓＋古琴＋二胡＋低音弦樂，跟著六幕起伏，S7 前靜音。先確認開源音樂模型的商用授權，不行就用程式合成鼓點與持續低音。

### 建議 5：分幕交付，每幕確認一次
4 分鐘一次做完風險很高。建議順序：
1. **第二幕（屋脊追逐，52 秒）** 先做成完整成品（含音效），當作品質樣板
2. 您確認風格後，再做其他五幕＋序幕＋尾聲
3. 全片串接、配樂、混音、最終渲染

每一幕給您一支 MP4 看。

### 建議 6：不照抄任何一部電影
所有鏡頭只借用「手法」，招式名、構圖、角色都是原創，可以安心放在營利頻道。
